How to install the APK
  1. Tap Download the APK and finish the steps on the next page.
  2. Open the downloaded file (Anonymous.apk).
  3. If Android asks, tap Settings and allow Install unknown apps for your browser or Files app. Then go back and tap Install.
  4. If Play Protect says it does not recognize the developer, tap More details, then Install anyway.
  5. Tap Open. You can turn the unknown apps setting off again.
